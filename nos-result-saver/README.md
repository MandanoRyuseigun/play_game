# NoS リザルト保存

Nebula on the Ship（Among Us MOD）でブラウザに表示されるリザルト（戦歴ブラウザ）を、**サーバー退出後も開ける1つのHTMLファイル**として保存するツールです。

## 使い方

1. `dist/install.html` をブラウザで開き、「💾 NoSリザルト保存」をブックマークバーへドラッグします（初回のみ）。
2. ゲーム終了後、**サーバーを抜ける前に**リザルトを普通のブラウザ（Chrome / Edge / Firefox）で開きます。
3. ブックマークの「💾 NoSリザルト保存」をクリックし、右下のパネルで **「保存（操作できる版）」** を押します。
4. ダウンロードされた `NoS_…html` をダブルクリックすれば、いつでもマップを確認できます。

Steam のゲーム内ブラウザではダウンロードできないため、URL を普通のブラウザで開き直してください。

### 2種類の保存方法

| ボタン | 中身 | 向いている場面 |
| --- | --- | --- |
| 保存（操作できる版） | ページのHTML・JS・CSS・画像と、ページが読み込んだ試合データを丸ごと埋め込み、通信を記録済みデータで再生する | マップの再生や切り替えなど、操作をそのまま残したいとき |
| 保存（見たまま版） | 今の画面をそのまま固める（canvas は画像化し、スクリプトは除去） | 操作できる版がうまく動かないときの保険 |

### ユーザースクリプト版（任意）

Tampermonkey などで `dist/nos-result-saver.user.js` を導入すると、localhost / 127.0.0.1 のページで保存パネルが自動で表示されます。ページを開いた瞬間からの fetch / XHR / WebSocket の通信内容を記録するので、ブックマークレットより再現性が高くなります。

## 仕組み

- **操作できる版**: ページのURLを取り直したHTMLに `<base>` と再生用シム（`src/shim.js`）を差し込みます。シムは `fetch` / `XMLHttpRequest` / `img.src` / `WebSocket` を差し替え、保存時に取得したデータを返します。ESモジュールは import 指定子を絶対URLに直したうえで、import map で data: URL に対応付けます。
- **見たまま版**: DOM を複製し、canvas を PNG 化、CSS と画像を data: URL で埋め込みます。

## 開発

```bash
npm install
```

```bash
npm run build   # dist/ を生成
```

```bash
npm test        # 模擬リザルトサーバーで「保存 → サーバー停止 → オフラインで開く」を確認（Playwright が必要）
```

`src/` が本体で、`dist/` は生成物です。

## 制限

- Nebula 本体のリザルトページのソースは非公開なので、一般的な Web ページの作りを前提にしています。テストは模擬ページで行っており、実物では未確認です。
- POST などで毎回内容が変わる通信や、保存時点までに読み込まれていないデータは再現できません。
- WebGL の canvas は「見たまま版」で真っ黒になることがあります。
