NoS リザルト保存 v__VERSION__

Nebula on the Ship のブラウザ版リザルト（戦歴ブラウザ）を、サーバー退出後も開ける1つのHTMLファイルとして保存します。

1. ブックマークレットを登録する（初回だけ）

  1. ブックマークバーを表示します（Chrome / Edge: Ctrl+Shift+B）。
  2. 下のボタンをブックマークバーへドラッグ＆ドロップします。
💾 NoSリザルト保存

ドラッグできない場合は、適当なページをブックマークし、その「URL」欄を下のコードに書き換えてください。

2. ゲーム終了後、サーバーを抜ける前に保存する

  1. いつも通りリザルトを普通のブラウザ（Chrome / Edge / Firefox）で開きます。
    Steamのゲーム内ブラウザではダウンロードできないので、そのURLを普通のブラウザで開いてください。
  2. ブックマークバーの「💾 NoSリザルト保存」をクリックします。右下に保存パネルが出ます。
  3. 「保存（操作できる版）」を押すと、HTMLファイルがダウンロードされます。
  4. あとはサーバーを抜けてOK。保存したファイルをダブルクリックすれば、いつでもマップを確認できます。

「操作できる版」がうまく動かないときは「見たまま版」も保存しておくと安心です（今の画面をそのまま画像化して固めます。再生などの操作はできません）。

3.（任意）自動で記録したい場合：ユーザースクリプト版

Tampermonkey などの拡張機能を使っている場合は、nos-result-saver.user.js を導入すると、リザルトを開くだけで保存パネルが表示されます。ページを開いた瞬間からの通信内容（WebSocket含む）も記録するので、ブックマークレット版より再現性が高くなります。

localhost / 127.0.0.1 のページで動作します。

4. 保存した試合をまとめて見る：戦歴ビューア

nos-viewer.html をダブルクリックで開き、保存したリザルトのファイルをドラッグ＆ドロップ（またはフォルダごと選択）すると、左に試合一覧が出て、選んだ試合をそのまま見られます。

読み込んだ試合はブラウザ内に記憶され、次に開いたときも一覧に出ます。ファイルがどこかに送られることはありません。

保存したファイルについて

  • 画像・スクリプト・試合データはすべてファイル内に埋め込まれます。ネット接続もゲームも不要です。
  • ファイルをそのまま友達に送れば、相手もブラウザで同じリザルトを見られます。
  • 左下に「保存版」バッジが表示されます（クリックで消えます）。
